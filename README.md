## 폴더 안내

| 폴더 | 내용 |
|---|---|
| `weekly/` | 주에 따른 진행상황 및 추후 계획 (매주 일요일) |
| `rewrites/` | 원본 코드·AI·검색 없이 스스로 재작성해본 python 파일 |
| `stuck/` | 작업 중 병목이 생긴 부분과 그 해결 과정 (막힘 → 원인 추측 → 실제 원인 → 해결) |
| `decisions/` | 되돌리기 어려운 설계 판단의 근거와 방향 |
| `interview-cards/` | 프로젝트를 끝낼 때마다, 왜·어떻게 만들었는지와 다시 한다면 어떤 방향으로 만들지 |
| `snippets/` | 여러 프로젝트에서 다시 쓸 코드 조각 |
| `p0-bootstrap/` | 착수 전 2주(P0)의 진단 결과와 연습 과제 |
