# Learning-log

결과가 아니라 과정

## 배경

KICPA 합격 후 데이터와 코딩을 공부하기 위한 개인 프로젝트.
재무제표·감사·밸류에이션 지식을 코드로 검증 가능한 분석 도구를 만드는 과정에서 데이터를 다루는 코딩 기술을 학습하는 것이 목적


## 레포 인덱스

| 코드 | 레포 | 기간 | 상태 |
|---|---|---|---|
| P1 | [fs-pipeline-dart](https://github.com/griffin10723-svg/fs-pipeline-dart) | 2026-10-04 ~ 10-31 | Stage 0 |

프로젝트가 시작될 때마다 한 줄씩 추가한다.

## 폴더 안내

| 폴더 | 내용 |
|---|---|
| `weekly/` | 주에 따른 진행상황 및 추후 계획 (매주 일요일) |
| `stuck/` | 작업 중 병목이 생긴 부분과 그 해결 과정|
| `decisions/` | 중요한 판단의 근거와 방향 |
| `interview-cards/` | 프로젝트를 끝낼 때마다, 왜·어떻게 만들었는지와 다시 한다면 어떤 방향으로 만들지 |
| `snippets/` | 여러 프로젝트에서 다시 쓸 코드 조각 |
| `p0-bootstrap/` | 착수 전 2주(P0)의 진단 결과와 연습 과제 |

## 규칙

- 하루에 커밋 1번 이상
- 매주 일요일 회고
- 커밋한 코드는 설명할 수 있어야 한다 (설명 못 하는 부분은 주간 회고에 기록)
